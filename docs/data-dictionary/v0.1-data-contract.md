# Data Contract v0.1

**Status:** IMPLEMENTED in schema (Alembic `0002_data_contract` + `0004_feature_snapshots`). Identity + Market 0 via `python -m app.ingest --backfill-contract`. Pregame rows: `python -m ml.features.build` (`BCW-SNAP-v0.1`).

This is the cheap-now, painful-later layer: one identity scheme, honest timestamps, and `league` on every core table so CFB does not force a rewrite.

Sign convention (**locked**): **home margin** \(M = \text{home_score} - \text{away_score}\). nflverse `spread_line > 0` ⇒ home favored. Convert favorite-centric copy only in the UI. See [04-bcw-v0.1.md](../roadmap/04-bcw-v0.1.md).

## Time fields (required mental model)

Every fact that can change has **when it happened in the world** vs **when BlueChip was allowed to know it**.

| Field | Meaning |
|-------|---------|
| `occurred_at` | When the event happened (kickoff, injury designation, line move). |
| `known_at` | Earliest time this fact could legally enter a prediction. Backtests at Friday 18:00 **cannot** use Saturday 22:14 `OUT`. |
| `retrieved_at` | When we fetched the source. |
| `effective_at` | Optional: when a status became official (may equal `occurred_at`). |
| `as_of` / `prediction_at` | Research clock for a model run: `T-24h`, `T-60m`, pregame. |

Predictions always record `prediction_at`. Experiments: **BCW Early / Saturday Night / Pregame** with different feature sets.

| Table | Internal id | External map |

| `leagues` | `NFL`, `CFB` | — |

## Cover vs push (pricing)

Rams −7 (home):

- cover: \(M > 7\)
- push: \(M = 7\)
- lose: \(M < 7\)

Normal \(M\) is a baseline. Discrete/key-number study (`experiments/nfl_margin_distribution.ipynb`) because 3, 6, 7, 10, 14 cluster. −6.5→−7 is not the same as −8.5→−9.
